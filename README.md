## ✨ 網站特色 (Features)

- **簡約現代設計 (Minimalist Modern)**：以地中海赤陶土色調、高雅襯線標題（Playfair Display）與現代無襯線（Plus Jakarta Sans）打造舒適排版。
- **經典城市深訪 (City Guides)**：收錄巴塞隆納、馬德里、塞維亞、格拉納達、聖塞巴斯提安、馬略卡島，具備互動式抽屜彈窗（Modal）瀏覽景點與在地小吃。
- **客製行程切換 (Curated Itineraries)**：支援「經典雙城 7 日」、「安達魯西亞熱情南境 8 日」、「巴斯克美食藝術 5 日」動態行程切換。
- **四季指南與節慶 (Seasonal Guide)**：春夏秋冬氣候特性、推薦出發月份與節慶評分。
- **行前必讀錦囊 (Travel Essentials)**：西班牙特有西斯塔（Siesta）作息、AVE 高鐵訂票、門票預約與防竊安全要點。
- **極致效能與響應式 (Responsive & Fast)**：原生 Vanilla HTML/CSS/JavaScript 開發，零外部龐大框架依賴，手機平板與桌面端皆完美適配。
